H2 Molecule Ground State Energy
===============================

This notebook demonstrates computing the ground state energy of the hydrogen molecule (H2) using the Variational Quantum Eigensolver (VQE) algorithm.

**Expected runtime**: 5-10 minutes (local simulation)

Learning Objectives
-------------------

1. Understand the VQE algorithm workflow
2. Learn about molecular Hamiltonians and qubit mapping
3. Visualize the ansatz circuit
4. Compare results against exact diagonalization

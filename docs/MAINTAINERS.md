## Responsibilities

Maintainers are responsible for:

1. **Code Quality**: Review PRs, ensure tests pass, maintain coding standards
2. **Documentation**: Keep docs up-to-date, review changes
3. **Releases**: Manage version bumps, publish to PyPI
4. **Community**: Respond to issues, guide contributors
5. **Security**: Review security-related changes, handle disclosures

## Becoming a Maintainer

To become a maintainer:

1. Make significant contributions to the project
2. Demonstrate commitment to code quality and community
3. Have your nomination approved by existing maintainers
4. Acknowledge the responsibilities

## Offboarding

Maintainers may step down by:
1. Opening an issue announcing the intent
2. Helping transition responsibilities
3. Transferring ownership of critical resources

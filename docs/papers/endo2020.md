## Summary

Comprehensive review of practical error mitigation techniques for near-term quantum devices, including Zero-Noise Extrapolation (ZNE), Dynamical Decoupling, and Virtual Distillation.

## Key Techniques

### 1. Zero-Noise Extrapolation (ZNE)

Increase noise level and extrapolate to zero noise:

```python
# In examples/noise_mitigation.py
noise_probs = [0.0, 0.01, 0.02, 0.03]
energies = [run_vqe(noise_prob=p) for p in noise_probs]
# Extrapolate to zero noise
```

### 2. Virtual Distillation (MITY)

Use multiple noisy states to reduce errors:

```python
# Combine multiple circuit executions
result = (E₁ + E₂ + E₃) / 3
```

### 3. Readout Error Mitigation

Correct measurement errors with calibration matrices.

## Implementation in VQE H₂

**File**: `examples/noise_mitigation.py`

```python
def create_noise_model(depolarizing_prob=0.01):
    noise_model = NoiseModel()
    single_qubit_error = depolarizing_error(depolarizing_prob, 1)
    two_qubit_error = depolarizing_error(depolarizing_prob * 2, 2)
    noise_model.add_all_qubit_quantum_error(single_qubit_error, ['u1', 'u2', 'u3'])
    noise_model.add_all_qubit_quantum_error(two_qubit_error, ['cx'])
    return noise_model
```

## Recommendations

| Technique | When to Use | Overhead |
|-----------|-------------|----------|
| ZNE | Circuit depth < 1000 | 2-4x |
| Virtual Distillation | Need higher accuracy | 3-10x |
| Readout Mitigation | All experiments | 2x |
